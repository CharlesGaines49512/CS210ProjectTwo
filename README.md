Summarize the project and what problem it was solving.

This project is an Investment Calculator designed to give users a visual example
of compound interest over time with and without monthly deposits. This program receives
user inputs of the initial investment amount, monthly deposit, annual interest rate,
and number of years for the projected growth. The output shows the year-end balance 
and interest earned of both scenarios. Providing the user with quick projections of 
compound interest growth.

What did you do particularly well?

The clarity and user-friendly design are the main strengths of this project.
Each output is aligned and legible as well as providing correct calculations within
it's scope. The user validation also enhances usability with asking for a correction
for any number that is not above zero.

Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?

This program could be improved for it's error handling as well. Having a try-catch
block for error handling could reduce the amount of code and help with maintanability.
Reducing the amount of printing in my main filed could also help with maintainability.


Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?

The most challenging part of this program was accurately following the loops for the 
compound interest and having the outputs align correctly. The continuous testing of the program
was the best way I knew way to work through the correct output. I also utlized search engines 
and Stack Overflow to work through my logic errors.

What skills from this project will be particularly transferable to other projects or course work?

This was my most extensive use of OOP principles at the time of this project. Combining
this with mathematical modeling brought a new skillset to utilize within programming. The use
of a header file was also a new process that made the clarity of the code shine through.
These are greate starting points for more advanced coursework and research projects with how
quickly data can be compiled and calculated.
